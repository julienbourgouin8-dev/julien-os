# Taxonomie produits CréA'deline — basée sur légendes Facebook + textes sur photos

Source : lecture de ~90 publications sur facebook.com/deline1001 (du post le plus récent, août 2026, jusqu'à l'origine de la page, décembre 2020/janvier 2021), croisée avec les textes déjà écrits SUR les photos (`assets/facebook/raw/`) et le tri visuel existant (`assets/facebook/tri/`, `assets/facebook/tri_tmp/`).

Règle suivie : chaque sous-catégorie ci-dessous est attestée soit par une légende Facebook écrite par Adeline, soit par un texte incrusté sur une photo. Rien n'est inventé. Quand une sous-catégorie est mentionnée sans photo retrouvable avec certitude, c'est noté explicitement.

Chemins de fichiers : tous relatifs à `assets/facebook/raw/<fichier>.jpg`.

## Notes de fiabilité

- Le compte Facebook était déjà connecté dans le navigateur — aucun mur de connexion rencontré, exploration directe possible.
- Plusieurs textes-parasites Facebook (chaînes de caractères combinés type "o͏p͏d͏t͏e͏") ont été rencontrés dans les métadonnées de posts partagés — ignorés comme prévu, ce n'est pas du contenu.
- Un certain nombre de fichiers `raw/` ont été trouvés **mal classés** dans le tri visuel initial (ex. le "Sac Mini Georges de Viny" et deux "sac banane" rangés dans `tri/trousses/`, deux protège-ardoises rangés dans `tri/pochettes/` et `tri/trousses/`). Ce ne sont que des observations de recherche — **aucun fichier n'a été déplacé**, conformément à la consigne de ne pas modifier le site ni les dossiers de tri.
- Les publications de type événementiel (marchés de Noël, salons, expos, reposts d'autres pages) ont été systématiquement écartées de cette recherche : elles ne révèlent pas de type de produit.
