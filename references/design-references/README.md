# Design references

Dossier créé le 2026-07-21 après un audit qui a trouvé qu'aucune capture
d'écran de référence design n'existait nulle part sur disque, alors que
Julien pensait en avoir déjà partagé comme référence de style. (L'audit
vivait dans un dossier de projet depuis supprimé — la conclusion reste
valable, seul le compte-rendu détaillé a disparu.) **Une image collée dans le chat ne persiste que dans la
transcription de cette conversation précise — elle n'est jamais sauvegardée
automatiquement.** Sans un geste explicite, elle est perdue dès que la
session se termine.

## Règle à appliquer dès qu'une référence visuelle est partagée

Dès que Julien partage une capture d'écran / un lien / une vidéo comme
référence de style ("fais un site comme ça", "j'aime cet effet", "voilà le
genre de rendu que je veux"), **la sauvegarder immédiatement ici** :

1. Fichier image dans ce dossier (nom descriptif, ex.
   `2026-07-21-hero-parallax-exemple.png`).
2. Une entrée dans `INDEX.md` (à créer au premier ajout) : date, fichier,
   ce que Julien a dit à propos, ce qu'il faut en retenir (la technique
   précise, pas juste "j'aime ce style").
3. Si la référence sert un projet précis, aussi pointer vers elle depuis le
   `CLAUDE.md` de ce projet.

Ne pas attendre qu'un skill (`visual-craft`, `site-revamp`) le demande — le
réflexe doit être immédiat, dans le tour de conversation où l'image arrive.

## Lien avec `visual-craft`

`visual-craft` (skill) grandit une technique à la fois à partir d'une
référence que Julien apporte — ce dossier est où cette référence doit vivre
une fois analysée, pas seulement dans le chat qui a servi à l'analyser.
